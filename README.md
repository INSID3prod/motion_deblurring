# Алгоритм устранения динамического смаза изображений
---
_Магистерская ВКР (Python, PyTorch)_ <br>
Исследование и разработка нейросетевого алгоритма устранения динамического смаза изображений с использованием частотного представления.

---
# Текущее состояние 
* Разработка архитектуры из двух модулей на основе U-Net: экстрактора признаков и генератора передаточной функции размытия в частотной области.
* Реализация устранения смаза в частотной области с использованием обратной Винеровской фильтрации.
* Применение комбинированной функции потерь в пространственной области: Charbonnier Loss и MAE для градиентов Щарра.
* Проведение экспериментов по обучению модели на случайных кропах одного изображения; работа над адаптацией модели для обучения на датасете GoPro.
