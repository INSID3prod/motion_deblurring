# Алгоритм устранения динамического смаза изображений
---
_Магистерская ВКР (Python, PyTorch)_ <br>
Исследование и разработка нейросетевого алгоритма устранения динамического смаза изображений с использованием частотного представления.

---
# Текущее состояние 
* Разработана архитектура из двух модулей на основе U-Net: экстрактора признаков и генератора передаточной функции размытия в частотной области.
* Реализовано устранение смаза в частотной области с использованием обратной Винеровской фильтрации.
* Примененена комбинированная функция потерь в пространственной области: Charbonnier Loss и MAE для градиентов Щарра.
* Проведены эксперименты по обучению модели на случайных кропах одного изображения; идет работа над адаптацией модели для обучения на датасете GoPro.
